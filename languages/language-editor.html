LANGUAGE EDITOR

한 문장씩, 새로운 언어로.

원문을 보며 번역을 입력해 주세요. 항목에 마우스를 올리거나 입력하면 오른쪽에서 표시 위치를 보여드립니다.

참고 언어

언어 파일(.h)을 올리면 편집할지 참고 언어로 추가할지 선택할 수 있습니다. 파일을 이 페이지에 끌어놓아도 됩니다.

한국어 원문을 준비하고 있습니다.

01

언어 정보

언어 메뉴에 표시할 이름을 직접 정해 주세요.

표시 이름은 해당 언어의 고유 표기를 권합니다. 언어 코드는 영문과 숫자, 하이픈으로 작성해 주세요.

02

문구 번역

입력하지 않은 항목은 빈칸으로 저장되며, 앱과 미리보기에서는 한국어로 표시됩니다. 입력 내용은 이 브라우저에 자동 저장됩니다.

참고 문구새 언어로 입력
표시 위치 미리보기
입력 즉시 반영
Skea Clock · 설정 메뉴

메뉴 순서와 하위 메뉴는 앱 소스에서 생성합니다. 알람 시간·파일·디스플레이 값은 예시입니다.

내려받은 파일은 앱의 우클릭 메뉴 → Language → 언어 파일 선택에서 적용할 수 있습니다.
