# Skea Clock 안내 및 오류 코드

[error.h](error.h)의 번호와 [ko.h](../../languages/ko.h)의 기본 한국어 문구를 함께 기록합니다. 프로그램은 선택한 표시 언어의 번역을 사용합니다.

1xx·2xx·3xx 오류창 하단에는 `(Error code: 101)`과 같은 형식으로 번호를 표시합니다. 0xx 안내창은 본문과 응답 버튼을 번호 없이 표시합니다.

## 0xx · 안내 및 확인

| 번호 | 사용자에게 표시되는 문구 | 발생 조건 및 처리 | 호출 위치 |
|---|---|---|---|
| **001** | 최신 업데이트가 있습니다. 다운받으시겠습니까?<br>버튼 **다운받으러 이동**, **취소** | 자동 업데이트 확인 결과 현재 EXE보다 새 버전이 있습니다. 이동 버튼을 누르면 GitHub 최신 릴리스 페이지를 엽니다. | [CheckUpdateResult](update.h#L137) |
| **002** | 실행한 버전이 이전에 사용한 버전보다 낮습니다.<br>`저장된 버전 → 실행한 버전`<br>버튼 **무시하고 실행**, **종료** | 실행한 EXE가 설정에 기록된 버전보다 낮습니다. 계속 실행하면 앱 시작 준비를 마친 뒤 실행한 버전을 기록합니다. 종료를 누르면 버전을 기록하기 전에 시작을 중단합니다. | [ConfirmSettingsDowngrade](settings-migration.h#L120) |

| **106** | 선택한 노래 파일을 재생하지 못했습니다. | 곡 검사에서 파일 오류를 확인했거나, 검사 통과 후 재생용 파일 복사 작업을 시작하지 못했습니다. | [WindowProc의 곡 선택 확인](../../skea-clock.cpp#L110) |

1xx 오류창은 경로가 있으면 본문과 오류 번호 사이에 사용자가 지정한 파일의 원본 경로를 표시합니다. 105는 선택된 곡이 없는 경우라 본문과 오류 번호만 표시합니다.
